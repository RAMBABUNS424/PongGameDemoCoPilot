# PongGameDemoCoPilot

A simple browser-based Pong game built with HTML, CSS, and JavaScript.

## Features

- Left paddle controlled by mouse or Arrow Up / Arrow Down
- Right paddle controlled by the computer
- Bouncing ball with wall and paddle collision detection
- Scoreboard for player vs CPU
- Restart flow with difficulty options
- Touch support for mobile devices
- Simple sound effects for hits and scoring

## How to Run

1. Clone the repository.
2. Open `index.html` in your browser.
3. Press the start button or hit the space bar to begin.

## Controls

- Mouse movement: moves the left paddle
- Arrow Up / Arrow Down: moves the left paddle
- Space: starts or restarts the game

## Project Structure

- `index.html` — game logic and UI
- `README.md` — project documentation

## Demo

Open the game locally in any modern browser to play.
